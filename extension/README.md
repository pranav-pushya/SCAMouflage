# PhishShield India - Chrome Extension

Real-time scam & phishing defender for WhatsApp, Gmail, Telegram, Outlook, Webmail, and active browser URLs. Tailored specifically for Indian cybercrime vectors (KYC, FASTag, Electricity disconnection, Digital Arrest, KBC/Lottery, and UPI fraud).

## 🚀 Key Features

1. **Real-Time Selection Scanner**:
   - Highlight any suspicious message or snippet in **WhatsApp Web**, **Gmail**, **Telegram Web**, **Outlook**, or any website.
   - A floating `[ 🛡️ Scan with PhishShield ]` button appears right above your selection.
   - Click to get an instant threat verdict (Safe, Suspicious, High Risk Phishing), risk score (0-100), detection signals, and advice.

2. **On-Screen URL Defender**:
   - Automatically monitors visited URLs and checks for brand spoofing (SBI, HDFC, ICICI, India Post, etc.), suspicious TLDs (`.xyz`, `.top`, `.click`), and direct APK downloads.
   - Shows an on-screen warning banner if you navigate to a high-risk phishing page.

3. **Context Menu Actions**:
   - Right-click any text or link: "🛡️ PhishShield: Scan Selected Message" or "Scan This Link".

4. **Extension Popup**:
   - Inspect active tab security status.
   - Paste or 1-click import message for analysis.
   - Dark & Light mode toggle matching PhishShield India's cyber aesthetic.
   - Toggle floating HUD, auto-scan, and URL warning banner.

5. **Helpline Integration**:
   - Direct alert to Indian National Cyber Crime Helpline **1930** and portal [cybercrime.gov.in](https://cybercrime.gov.in).

---

## 🛠️ How to Install in Google Chrome / Brave / Edge

1. Download or extract the extension folder: `phishshield-extension`.
2. Open Google Chrome and type `chrome://extensions` in the address bar.
3. Toggle ON **Developer mode** in the top right corner.
4. Click **Load unpacked** in the top left corner.
5. Select this `phishshield-extension` directory.
6. The PhishShield India shield icon will appear in your Chrome toolbar!
